# 🔥 Fire Cursor – Cursor Emits Sparks Like a Sparkler

> A dazzling, fiery cursor effect where the cursor emits sparks like a sparkler, creating a captivating, energetic visual experience.

---

## 📖 Description

The **Fire Cursor** is a dazzling, fiery cursor effect where the cursor emits sparks like a sparkler. As you move your mouse, warm-colored sparks spray outward in random directions, creating a captivating, energetic visual experience reminiscent of a sparkler on a summer night. The sparks have varying sizes, colors (orange, red, yellow, gold), and trajectories, with a soft glow that adds to the magical feel.

The component uses JavaScript to create a continuous stream of sparks behind the cursor with random properties. Each spark follows a ballistic trajectory, fading out as it travels. Clicking creates a large fire burst with 50 sparks, and hovering over interactive elements triggers a smaller burst of 25 sparks.

Perfect for fiery-themed interfaces, celebrations, creative portfolios, and any application where you want to create a dazzling, energetic cursor effect. The Fire Cursor transforms a simple cursor into a sparkler-like spectacle.
